# Application Tracker + Cadence

Job hunting is a pipeline, not a lottery. Pipelines get managed with the
same discipline as the study tracker: steady input, measured conversion,
weekly review. This file is the tracker AND the operating rules; keep both
here so the review can't skip the rules.

---

## Operating Rules

1. **Cadence: 8–10 tailored applications/week.** Tailored = resume keywords
   mirrored to the posting + 3-sentence cover note. Not 50 blind sprays —
   conversion, not volume. (Quality bar: could you say in one sentence why
   THIS posting? If not, skip it.)
2. **The 60% rule:** meet ~60% of listed requirements → apply. Junior
   postings are wishlists written by people who won't run the interview.
   "3–5 years experience" on a junior posting means "not a total beginner"
   — eighteen months of documented homelab + nine years of work history
   clears it.
3. **Referrals outrank applications ~10:1.** For any posting that excites
   you: find an engineer at the company (LinkedIn), short message — one
   specific thing about their infra/product, one line on you, ask for 15
   minutes, NOT for a job. Two of these per week minimum.
4. **Follow up once**, 7–10 days post-application, short and specific. Then
   let it go — the pipeline replaces hope with the next application.
5. **Every interview gets a debrief row** — questions asked, where it
   wobbled. Wobbles become drill requests. An interview that produces no
   learning was wasted twice.

## Weekly Review (Sundays, after the study ritual slot frees up post-exam)

- Applications sent this week: __ (target 8–10)
- Responses / screens / technicals this cycle: __ / __ / __
- **Response rate check:** under ~10% after 40+ applications = the resume
  or targeting is broken, not the market. Fix inputs before adding volume:
  re-read `resume-translation.md`, tighten role targeting, add referrals.
- Screens that didn't convert to technicals = story problem → interview-prep.
- Technicals that didn't convert = knowledge gap → name it, drill it.
