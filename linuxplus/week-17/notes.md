# Week 17: Security & Vulnerability Scanning
**Date:** June 29, 2026
**Estimated Time:** 5-8 hours

## Objectives
- Identify and remediate security issues in your network.
- Master Nmap for network discovery and security auditing.
- Use Lynis for comprehensive system security audits.
- Understand vulnerability assessment concepts like CVE and CVSS.

## Key Concepts
- **Port Scanning**: Identifying open ports and services.
- **Service Fingerprinting**: Determining service versions.
- **Vulnerability Assessment**: CVE (Common Vulnerabilities and Exposures).
- **Hardening**: Attack surface reduction and defense in depth.
