# Week 14: Advanced Scripting & Cron (Part 2)
**Date:** June 8, 2026
**Estimated Time:** 5-8 hours

## Objectives
- Reinforce Bash functions and arrays.
- Practice error handling (`set -e`, `trap`) and debugging (`set -x`).
- Deepen understanding of `cron` and `crontab` management.
- Automate complex routine tasks with scripts.

## Key Concepts
- **Functions**: Reusable code blocks within scripts.
- **Arrays**: Storing multiple values in a single variable.
- **Error Handling**: Using `set -e` to exit on error and `trap` for cleanup.
- **Debugging**: Using `set -x` to trace script execution.
- **Cron**: Time-based job scheduler.
- **Crontab**: Configuration for scheduled jobs.
