# Week 15: APT Package Management
**Date:** June 15, 2026
**Estimated Time:** 5-8 hours

## Objectives
- Master `apt` package management on Ubuntu and Debian-based systems.
- Understand the difference between `apt` and `apt-get`.
- Manage repositories, `sources.list`, and PPAs.
- Use `dpkg` for low-level package operations.
- Handle dependencies and package troubleshooting.

## Key Concepts
- **APT**: High-level package management tool.
- **Repositories**: Servers where packages are stored.
- **sources.list**: Configuration file for repository locations.
- **PPA**: Personal Package Archives for newer software versions.
- **dpkg**: Debian package manager (backend for apt).
- **Dependencies**: Packages required by other packages to function.
