- Manage default permissions using `umask`.

- Apply permissions to Gitea server infrastructure (Exam Objective 2.4).

## Key Concepts
- **SUID (Set User ID)**: Runs with the owner's permissions (Numeric: 4000).
- **SGID (Set Group ID)**: Runs with the group's permissions (Numeric: 2000).
- **Sticky Bit**: Only the file owner or root can delete files (Numeric: 1000).
- **umask**: Default permission mask for new files and directories.
- **ACLs**: Granular permissions beyond standard rwx.
