# Week 7: Systemd Service Management
**Date:** April 20, 2026
**Estimated Time:** 5-8 hours

## Objectives
- Understand systemd units and unit files.
- Manage services using `systemctl` (start, stop, enable, disable).
- Analyze system logs using `journalctl`.
- List and verify system services (Exam Objective 1.3).

## Key Concepts
- **systemd**: System and service manager (replaces init).
- **Units**: Configuration files representing services (.service), targets (.target), and more.
- **systemctl**: Command-line tool for managing systemd.
- **journald**: Logging service for systemd.
