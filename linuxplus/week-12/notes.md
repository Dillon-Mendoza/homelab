# Week 12: Log Management & Analysis
**Date:** May 25, 2026
**Estimated Time:** 5-8 hours

## Objectives
- Complete centralized logging for all tiers (Laptop, WSL, Pi Zero, Pi 4).
- Understand and configure log rotation using `logrotate`.
- Practice log analysis using `grep`, `awk`, and `sed`.
- Analyze and troubleshoot system properties and network resource issues (Exam Objectives 2.1, 4.2).

## Key Concepts
- **Log Rotation**: Why rotate? Prevent disk space exhaustion.
- **logrotate**: Configuration (`/etc/logrotate.conf`, `/etc/logrotate.d/`), compression, retention.
- **Log Analysis**: Using `grep` for pattern matching and `awk` for field extraction.
- **Centralized Infrastructure**: Fedora server collecting logs from all tiered devices.
