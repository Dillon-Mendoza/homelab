# Week 16: Package Management (DNF/RPM)
**Date:** June 22, 2026
**Estimated Time:** 5-8 hours

## Objectives
- Manage packages on both Debian and Fedora-based systems.
- Compare RPM and DNF package managers.
- Configure repositories and EPEL.
- Manage transaction history and automatic updates.

## Key Concepts
- **DNF vs YUM**: Modern replacement for YUM.
- **RPM package format**: Low-level package manager (like dpkg).
- **Repositories**: `.repo` files in `/etc/yum.repos.d/`.
- **EPEL**: Extra Packages for Enterprise Linux.
- **Transaction History**: Tracking installs/upgrades with `dnf history`.
