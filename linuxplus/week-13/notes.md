# Week 13: Advanced Scripting & Cron
**Date:** June 8, 2026
**Estimated Time:** 5-8 hours

## Objectives
- Understand and use Bash functions and arrays.
- Implement error handling (`set -e`, `trap`) and debugging (`set -x`).
- Manage scheduled tasks using `cron` and `crontab`.
- Automate routine tasks with scripts.

## Key Concepts
- **Functions**: Reusable code blocks within scripts.
- **Arrays**: Storing multiple values in a single variable.
- **Error Handling**: Using `set -e` to exit on error and `trap` for cleanup.
- **Debugging**: Using `set -x` to trace script execution.
- **Cron**: Time-based job scheduler in Unix-like systems.
- **Crontab**: Configuration file that defines the scheduled jobs.
